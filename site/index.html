Baixar para Windows

Windows 10 ou 11 (64 bits)

  1. Clique em Baixar para Windows e abra o arquivo baixado.
  2. Se aparecer "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo.
  3. Conclua a instalação e entre com o e-mail e a senha liberados pelo administrador.
Instale só uma vez: depois disso o sistema se atualiza sozinho sempre que sair uma versão nova.
